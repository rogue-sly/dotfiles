# My Neovim Config

This is my Neovim config, which is now split into two profiles: **Laptop** and
**Termux**. My philosophy remains to keep things as slim as possible while
providing a "good enough" environment.

This neovim configuration provides support for various language
tools(formatters, linters, language servers).

It primarily targets the following:

- Rust
- C/C++ and [Meson](https://mesonbuild.com/)
- Taking notes with [zk](https://github.com/zk-org/zk)
- Writing documents with [typst](https://typst.app/)
